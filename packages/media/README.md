# 媒体分析与执行

状态：职责目录，尚无可导入的媒体处理包或渲染入口。

计划封装 FFmpeg、OpenCV、PySceneDetect 和 Librosa，处理探测、关键帧、切镜、代理、质量与重复分析、音频特征、时间轴校验和渲染。

后续可按 `probe/`、`analysis/`、`timeline/`、`render/` 分离职责。具体支持格式、帧率、时间单位、编解码器和导出参数经样例验证后确定。

渲染前校验素材引用、源范围、轨道、转场重叠、字幕声音与锁定条件。FFmpeg 使用参数数组和受控模板，限制工作路径与资源。局部重规划可以减少部分重复处理，最终 MP4 仍可能需要完整重新编码，不预先承诺局部渲染效果。

初始化时补齐依赖、FFmpeg 构建说明、样例命令、兼容性与错误恢复验证。
