# AI 与多角色编排

状态：职责目录，尚无可导入的 Python 包、模型服务或 LangGraph 工作流。

计划按以下布局逐步实现：

| 后续目录 | 职责 |
| --- | --- |
| `agents/` | 导演、编剧、视觉、摄影、剪辑、声音、审片七类角色 |
| `workflows/` | 依赖、检查点、人工确认、补拍与局部重规划 |
| `providers/` | 文本、视觉、转写及其他模型能力的可替换适配器 |
| `prompts/` | 按角色和版本维护的提示模板 |
| `evaluations/` | 检索、叙事、缺口、局部修改和审片效果评测 |

角色输入输出须符合共享契约并保留素材来源与不确定性。工作流显式处理冲突、预算、格式修复与网络重试上限；模型输出不得直接成为 shell 命令。

模型提供商、型号、权重、许可证与部署资源待验证。固定样例、模拟结果和真实模型输出应清楚区分，不能把未验证的识别结果作为事实。包名称、安装方式和依赖版本随实际初始化补齐。

完整职责、输出信封、工具权限、状态图、人工中断、预算与评测见 [Agent 设计](../../docs/design/agent-design.md)。
