# 覆盖与角色约束内核

`src/sw_ai/coverage.py` 实现：同项目证据解析入口、四态覆盖合成、按素材合并重叠区间计时、上传与补拍验证分离，以及七角色信封的证据/副作用约束。

覆盖状态为 `covered / insufficient / uncertain / missing`。检索未完成不能判为 missing。语义支持和质量可用标记来自显式人工固定输入，本包尚未接入真实素材理解模型。

补拍验证绑定任务修订、故事修订、分析引用和重新计算的覆盖报告。调用方提供的成功分析集合必须由未来业务服务从可信持久化事实取得；当前用于离线规则回放，不提供客户端自证完成接口。

共享引用校验实际位于 `sw_contracts.validation`，媒体包无须依赖 AI 包。七角色尚无 LangGraph 运行图、模型预算或恢复执行器；接口边界及后续工作见 [Agent 设计](../../docs/design/agent-design.md)。
