# API 设计入口

状态：接口职责规划，尚无运行中的接口或 OpenAPI 规范。此处不预先列出可调用的 URL。

| 领域 | 计划职责 |
| --- | --- |
| 身份与权限 | 确认用户、项目访问范围和操作权限 |
| 项目与意图 | 创建项目、确认目标与约束 |
| 素材与上传 | 上传会话、分片与校验、元数据和授权记录 |
| 分析与检索 | 受理分析、状态查询、候选片段与来源区间 |
| 故事与补拍 | 节点、素材覆盖、缺口、任务与用户选择 |
| Agent 与任务 | 依赖、阶段、决策摘要、重试和人工确认 |
| 时间轴与版本 | 编辑草案、差异、锁定校验、确认提交和恢复 |
| 审片与导出 | 问题定位、预览、导出任务与版本产物 |

首次实现需统一鉴权、标识、时间单位、分页、错误结构、任务状态与接口版本策略。耗时接口返回任务标识，状态由查询接口与后续 WebSocket 通知提供；上传成功不表示处理成功。

修改请求应包含基准版本、目标、操作和约束，先返回差异草案，由确认动作生成新版本。导出只接受通过校验的版本，鉴权和具体路由随实现冻结。

FastAPI 工程建立后，在这里记录 OpenAPI 的生成与检查方式，并与 [共享契约](../../packages/contracts/README.md) 保持一致。
