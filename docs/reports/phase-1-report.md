## 2. 创新机制与本阶段证据

### 2.1 证据驱动的故事覆盖与补拍验证

故事节点与证据区间绑定，覆盖判定保留 `covered / insufficient / uncertain / missing`。检索未完成不能据此宣告缺失；素材有语义支持但质量或时长不足时保留不足状态。补拍上传只表示提交，新证据必须通过引用和覆盖验证才允许完成任务。

相对“先生成故事、再人工找素材”和“有上传就关闭补拍”的拟设简化方案，本次实现给出了可执行的证据约束与状态门。实际结果可证明这些规则在当前固定输入上的行为；尚未运行真实素材对照，不能据此宣称缺口准确率提升或减少了多少补拍。

### 2.2 依赖感知的局部重规划基础

编辑前固定目标和批准范围，在小型 DAG 上传播影响并输出原因。候选生成后比较完整差异，分别检查锁定内容与范围外变化；合法开场替换通过，锁定采访/结尾变化、删除后换键和范围外字幕变化被拒绝。确认时核对草案摘要及显式解锁键。

相对“每次整片重新生成”和“只靠提示词要求保护片段”的拟设简化方案，本次交付了确定性的修改约束。候选仍由样例提供，未实现完整自然语言求解，也未测量规划耗时、重算量或创作质量收益。

### 2.3 Agent 协作的支撑边界

七角色使用统一角色信封、证据引用和副作用边界；固定角色输出不能自行解锁或提交版本。七角色数量和框架选型不单独作为创新结论。真实角色协作、预算、冲突恢复与中断续跑尚未实现，其收益按[评测协议](../evaluation.md)的 D3 消融验证。

## 3. 工程、数据库与契约

| 层 | 当前入口/实现 | 约束与限制 |
| --- | --- | --- |
| Web | `apps/web`，Vue / Pinia / TypeScript / Vite | 实际 API 读写；Schema 由 Ajv 校验并补充业务语义检查 |
| Flutter | `apps/mobile`，Android/Web 工程 | Web 实测；客户端实现当前生成 Schema 子集，后续扩展需同步用例 |
| API | `services/api/src/sw_api`，FastAPI | 持久化身份、项目授权、开发回放、媒体探针；回放为同步入口 |

| 规则 | `packages/ai`、`packages/media` | 覆盖/补拍门、依赖探针、EDL 校验与草案摘要 |
| Worker | `services/worker` | 六态与合法状态转移；尚无 Celery 执行、Outbox、租约和恢复 |

首迁移落实 users、auth_sessions、projects、project_members、stored_objects、assets、jobs、analysis_runs、segments、api_idempotency。`phase_one_datasets` 仅为开发样例容器，不作为正式故事或版本事实源。迁移使用版本内冻结快照，后续修改新增迁移。

当前 UUID 使用 String(36)，JSON 使用通用 JSON；完整数据库设计中的原生 UUID、JSONB、pgvector、完整审计字段和其余 26 张业务表留待后续。真实 PostgreSQL 已验证迁移往返、metadata 一致、项目复合外键、约束、并发幂等/导入及失败事务回滚；这些检查不代表完整生产事务已验收。

开发回放默认关闭；生产环境拒绝启用回放。媒体上传探针与固定人工元数据分别展示，不会把 ffprobe 的媒体参数冒充语义理解结果。正式版本发布仍需不可变快照、项目头并发和事务实现。

## 4. 样例 A：故事覆盖与补拍验证门

输入为项目自编的校园活动元数据和人工标注，不含第三方原片；“开场环境—活动过程—人物感受—结束告别”四个节点均有明确要求。完整输入、预期值、实际输出和输入摘要见[回放记录](evidence/replay.json)。

| 检查 | 实际输出 | 含义 |
| --- | --- | --- |
| 开场/活动过程 | covered | 当前标注满足要求及规则条件 |
| 人物感受 | insufficient | 有支持但质量不可用 |
| 结束告别，检索完成 | missing | 限定输入中无支持证据 |
| 结束告别，检索未完成 | uncertain | 不把未完成检索误报为缺失 |
| 上传补拍 | submitted | 上传不会直接完成任务 |
| 加入新人工标注并通过验证 | fulfilled | 固定新证据通过验证门；不是模型分析结果 |

额外测试覆盖重叠区间去重、非法区间、错误分析来源、陈旧任务/故事板修订、缺失验证依据及用户略过。略过只改变处置，不改写覆盖事实。

## 5. 样例 B：开场替换与修改保护
