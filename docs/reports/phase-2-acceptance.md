## 3. A/B 定位计时

1. 观察员复跑脚本后，先固化查询、Top-5、文件/片段候选和区间规则。候选从同批素材的相同时间戳转写生成。当前诊断用登记中的 `anchor_ms` 作为接受区间内的锚点；正式计时可由独立标注员预先冻结目标区间，例如报告的毫秒时间点落在标注区间内，或者距边界不超过 1,000 ms。选定口径后两组不改动。参与者不能看到标注。
2. **A** 只给查询和脚本 `query_records.a_assets` 中按序的文件候选，从 0 秒手动定位。**B** 在素材工作区给同一查询的片段候选，可以点击“回看片段”定位。尽量使用同一设备和播放器、相同代理或相同编码媒体，清空之前的回看状态。
3. 结果首次可用时开始计时；参与者报告正确原片和时间点、观察员验证后停止。每条上限 60 秒；超时、错误定位和无命中分别记录。无答案查询单独记有无误返回和人员是否正确弃答，不纳入定位用时。至少采用互换分配：成员甲对一部分查询做 A、其余做 B，成员乙做相反分配；若同一人重复看同一素材，必须报告记忆偏差，不能声称盲测。
